# 🧠 Deep Learning Face Recognition 🎥

This project implements a **deep learning–based face recognition system** that uses a webcam to detect and recognize human faces in real time. The application accesses the system camera through the `demp.py` script and applies deep learning and computer vision techniques to identify faces from live video input.

The project demonstrates practical usage of **Convolutional Neural Networks (CNNs)** and image processing for real-time face recognition. It can be extended for applications such as **attendance systems, authentication, and surveillance**.

## 📁 Project Structure

Deep-Learning/
│
├── demp.py              🎯 Main script for camera access & face recognition  
├── requirements.txt     📦 Required Python libraries  
├── README.md            📄 Project documentation  

## ⚙️ Requirements

Ensure **Python** is installed on your system.  
Install dependencies using:

pip install -r requirements.txt

## ▶️ How to Run the Project

1️⃣ Clone the repository:  
git clone https://github.com/lakshmiprasannaponnaganti23-debug/Deep-Learning.git

2️⃣ Navigate to the project directory:  
cd Deep-Learning

3️⃣ Install dependencies:  
pip install -r requirements.txt

4️⃣ Run the application:  
python demp.py

🎥 The camera will open and start real-time face recognition.
